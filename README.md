# おおきなカブと てんびん

昔話『大きなカブ』をもとにした、重さ合わせの算数パズルゲームです。
カブは、**カブと同じ重さ**の仲間で引っぱらないと抜けません。

▶ あそぶ: https://konbu-love.github.io/ookina-kabu/

スマートフォンのブラウザで遊べます。対象は小学1年生くらいです。

## あそびかた

- 天秤の片側にカブ、もう片側の皿に仲間をのせます。
- 仲間を指でドラッグして皿にのせ、皿の外へ出すとおろせます。
- 全部の天秤が水平になったらカブが抜けます。
- 正解したときに皿にのっていた仲間だけで、カブを引き抜く場面が流れます。

## モード

| モード | 内容 |
|---|---|
| 📖 おはなし | 紙芝居でルールが分かる物語。最後にチュートリアルの問題を解きます。いつでもスキップできます。 |
| ⚖ れんしゅう | 天秤の形とカブの大きさを選んで、自動で作られる問題をくり返し解きます。 |
| 💪 やる気のある おじいさん一家 | 全員が皿にのった状態から始まり、疲れた人を外に出していきます。帰った人は戻ってきません。 |

**天秤の形**
- 1たい1: カブ1つと皿1つ
- 1たい2: 片側に小さな天秤がぶら下がるモビール型
- 3だん: 3段のモビール型

**カブの大きさ**
- 小カブ: 合計10まで
- 大カブ: 合計20まで
- とく大カブ: 合計50まで

## せってい

| 項目 | 選べるもの |
|---|---|
| カブを ぬく えんしゅつ | ON / OFF(OFFで、正解後すぐ次の問題へ) |
| もじ | 1年生の漢字まで / ぜんぶひらがな |
| がめんの むき | よこ / たて / じどう |
| 音 | ON / OFF |

設定はブラウザに保存され、次回も残ります。
「よこ」「たて」を選ぶと、遊び始めるときに全画面になり、スマホを回しても向きが変わりません。

## つくり

- `index.html` 1ファイルで動きます(HTML / CSS / JavaScript)。
- 画像は `img/` フォルダの WebP ファイルです。
- 効果音は音声ファイルを使わず、ブラウザで鳴らしています。
- 問題は毎回自動で作られ、必ず解ける組み合わせになっています。
